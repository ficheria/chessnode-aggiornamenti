# Aggiornamenti di Chess Node

Qui stanno gli aggiornamenti dell'app Chess Node, che arrivano sul telefono senza reinstallare.

L'app legge [manifest.json](manifest.json) (firmato da Chess Node) e scarica lo zip della versione nuova. Senza la firma giusta l'aggiornamento non viene accettato.

Indirizzo del manifest: <https://ficheria.github.io/chessnode-aggiornamenti/manifest.json>
